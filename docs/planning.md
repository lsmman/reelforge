# reelforge 기획 메모

작성: 2026-09-06

## 확정된 것

- **정체**: AI 생성 파이프라인. 프롬프트·대본을 입력하면 AI가 이미지를 생성하고
  그 이미지들을 영상으로 연결한다. 사용자가 가진 이미지를 올려 편집하는 변환기가
  아니라, 생성이 출발점이다.
- **형태**: Next.js 웹 앱. TypeScript/React.
- **생성 백엔드**: Higgsfield, Sora 같은 이미지·영상 생성 API를 붙인다.
  (어느 것을 쓸지는 미정)

## 열린 질문

- 파이프라인 어디까지 자동화할지 — 대본 분할, 장면 프롬프트 생성, 이미지 생성,
  영상 합성 중 사람이 개입하는 지점.
- 영상 합성을 브라우저에서 할지(WebCodecs) 서버에서 할지(ffmpeg).
- 생성 API 선택과 비용 구조.
- 내레이션·자막·BGM 포함 여부.
